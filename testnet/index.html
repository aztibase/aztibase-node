Developer Guide: Use the Testnet

1Get testnet tokens

Visit the faucet and enter your wallet address. You'll receive 10 AZTB (rate limited to 1 request per 60s).

2Query your balance 
curl -X POST https://testnet1.aztibase.com:9944 \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"aztb_getBalance","params":["YOUR_ADDRESS"],"id":1}'
3Send a transfer

Use the WASM SDK or CLI wallet to sign and broadcast a transaction:

# Generate a wallet
aztibase wallet generate --mnemonic --passphrase "your-passphrase" --output wallet.json

# Send tokens
aztibase wallet transfer \
  --keyfile wallet.json \
  --passphrase "your-passphrase" \
  --to RECIPIENT_ADDRESS \
  --amount 100 \
  --rpc https://testnet1.aztibase.com:9944
4Explore blocks and transactions

Use the block explorer to view blocks, transactions, and account balances in real time.

Run a Validator Node

1System requirements
ComponentMinimumRecommended
CPU2 cores4+ cores
RAM4 GB8+ GB
Disk40 GB SSD100+ GB NVMe
Network100 Mbps1 Gbps
OSUbuntu 22.04+ / Debian 12+ / any Linux with glibc 2.31+
2Quick install (Ubuntu)

Run the bootstrap script to install, build, and configure automatically:

curl -sSf https://raw.githubusercontent.com/user/aztibase/dev/deploy/bootstrap.sh | bash

Or build manually:

# Install Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Clone and build
git clone https://github.com/user/aztibase.git
cd aztibase
CARGO_INCREMENTAL=0 cargo build --release -p aztibase-node

# Binary is at target/release/aztibase
3Generate validator keys 
# Generate a new validator keypair with BIP-39 mnemonic
./target/release/aztibase wallet generate \
  --mnemonic --passphrase "your-secure-passphrase" \
  --output validator.json

# Show your validator address
./target/release/aztibase wallet show validator.json \
  --passphrase "your-secure-passphrase"

IMPORTANT: Back up your validator.json and mnemonic phrase. Loss means loss of stake.

4Get testnet AZTB and stake

Use the faucet to fund your validator address. Minimum stake: 10,000 AZTB.

Send a stake transaction from your validator address to register as a validator.

5Start your node 
# Run with the testnet profile
./target/release/aztibase \
  --testnet \
  --validator-key validator.json \
  --data-dir ./data \
  --metrics

# Or use systemd (if installed via bootstrap.sh)
sudo systemctl start aztibase
sudo journalctl -u aztibase -f
6Verify your node 
# Check health
curl http://localhost:9944/health

# Check node info
curl -X POST http://localhost:9944 \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"aztb_nodeInfo","params":[],"id":1}'

# Check metrics
curl http://localhost:9944/metrics

Testnet Rules

  • Testnet tokens (AZTB) have no monetary value.
  • The network may be reset without notice during the testnet phase.
  • Report bugs and issues on GitHub.
  • Rate limits apply: 100 RPC requests/second per IP, faucet 1 drip/60s.
  • Validators may be slashed for equivocation or extended downtime.
