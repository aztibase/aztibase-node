<div class="arch-section">
  <div class="arch-inner">
    <div class="arch-header">
      <p class="section-eyebrow">Architecture</p>
      <h2 class="section-title">How it works</h2>
    </div>
    <div class="arch-lead">
      <div class="arch-lead-item">
        <h3 class="arch-lead-title">Synaptic Consensus</h3>
        <p class="arch-lead-body">
          DAG-based SynBFT with Proof of Useful Work. Blocks reference multiple parents —
          no single chain bottleneck. 2/3 supermajority finality in 4 rounds. Leader election
          via VRF, round-paced at 400ms.
        </p>
      </div>
      <div class="arch-lead-item">
        <h3 class="arch-lead-title">Server-Independent</h3>
        <p class="arch-lead-body">
          Every component works if all centralized servers go offline. Peer discovery via
          Kademlia DHT, QUIC transport, gossipsub mesh. No DNS seeds, no bootstrap servers,
          no single points of failure.
        </p>
      </div>
    </div>
    <hr class="gold-rule"/>
    <div class="arch-grid">
      <div class="arch-item">
        <span class="arch-item-label">AI Runtime</span>
        <span class="arch-item-desc">On-chain verification, off-chain inference. Model registry and compute market at L1.</span>
      </div>
      <div class="arch-item">
        <span class="arch-item-label">Dual VM</span>
        <span class="arch-item-desc">WASM and EVM side by side. Deploy in Rust, AssemblyScript, or Solidity.</span>
      </div>
      <div class="arch-item">
        <span class="arch-item-label">Verkle Trees</span>
        <span class="arch-item-desc">Verkle commitments for state proofs — smaller than Merkle, enabling stateless validation.</span>
      </div>
      <div class="arch-item">
        <span class="arch-item-label">Pure Rust</span>
        <span class="arch-item-desc">One C dependency (blst for BLS12-381). Everything else — redb, BLAKE3, Ed25519 — native Rust.</span>
      </div>
      <div class="arch-item">
        <span class="arch-item-label">Chrome Wallet</span>
        <span class="arch-item-desc">Browser extension with send, stake, delegate. AES-256-GCM keys, TOTP + WebAuthn 2FA.</span>
      </div>
      <div class="arch-item">
        <span class="arch-item-label">WASM Staking</span>
        <span class="arch-item-desc">Compile-to-browser staking transactions. Client-side signing with full type safety.</span>
      </div>
    </div>
  </div>
</div>
