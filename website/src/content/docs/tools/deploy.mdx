Aztibase supports two virtual machines — deploy in **Solidity** (EVM) or **Rust/AssemblyScript** (WASM).

## EVM Contracts (Solidity)

### Using the CLI

```bash
# Compile your contract
solc --bin --abi MyContract.sol -o build/

# Deploy via RPC
curl -X POST https://rpc.aztibase.com \
  -H 'Content-Type: application/json' \
  -d '{
    "jsonrpc": "2.0",
    "method": "aztb_sendTransaction",
    "params": ["0x<signed-deploy-tx-hex>"],
    "id": 1
  }'
```

## WASM Contracts (Rust)

### Write your contract

```rust
#[no_mangle]
pub extern "C" fn call() {
    // Read input
    let input = aztb::input();
    // Process
    let result = process(input);
    // Return output
    aztb::ret(&result);
}
```

### Compile to WASM

```bash
cargo build --target wasm32-unknown-unknown --release
wasm-opt -Oz target/wasm32-unknown-unknown/release/my_contract.wasm -o optimized.wasm
```

### Deploy

```bash
# The WASM bytecode is deployed using TxKind::DeployWasm (0x0B)
# Use the wallet extension or construct the transaction manually
```

## Transaction Types

| TxKind | Hex | Purpose |
|--------|-----|---------|
| `DeployEvm` | `0x0A` | Deploy an EVM contract |
| `DeployWasm` | `0x0B` | Deploy a WASM contract |
| `CallEvm` | `0x0C` | Call an EVM contract |
| `CallWasm` | `0x0D` | Call a WASM contract |
| `CrossVmCall` | `0x1A` | Call across VMs (WASM↔EVM) |

## Gas Costs

| Operation | Gas |
|-----------|-----|
| Transfer | 21,000 |
| EVM deploy | ~200,000 - 2,000,000 |
| WASM deploy | ~100,000 - 1,000,000 |
| EVM call | ~30,000 - 500,000 |
| WASM call | ~20,000 - 300,000 |
| Cross-VM call | +50,000 overhead |

## Verification

After deployment, verify your contract is live:

```bash
# Check contract code exists
curl -X POST https://rpc.aztibase.com \
  -H 'Content-Type: application/json' \
  -d '{
    "jsonrpc": "2.0",
    "method": "aztb_getCode",
    "params": ["0x<contract-address>"],
    "id": 1
  }'

# Check account type is "Contract"
curl -X POST https://rpc.aztibase.com \
  -H 'Content-Type: application/json' \
  -d '{
    "jsonrpc": "2.0",
    "method": "aztb_getAccountType",
    "params": ["0x<contract-address>"],
    "id": 1
  }'
```

<script>{`
(function() {
  const RPC = 'https://rpc.aztibase.com';
  const btn = document.getElementById('deploy-estimate');
  const result = document.getElementById('deploy-result');

  function showResult(msg, ok) {
    result.textContent = msg;
    result.className = 'deploy-result ' + (ok ? 'success' : 'error');
    result.style.display = 'block';
  }

  btn.addEventListener('click', async function() {
    const bytecode = document.getElementById('deploy-bytecode').value.trim();
    const from = document.getElementById('deploy-from').value.trim();
    const gas = document.getElementById('deploy-gas').value.trim();

    if (!bytecode.match(/^0x[0-9a-fA-F]+$/)) {
      showResult('Invalid bytecode. Must start with 0x followed by hex.', false);
      return;
    }
    if (!from.match(/^0x[0-9a-fA-F]{64}$/)) {
      showResult('Invalid address. Must be 0x + 64 hex characters.', false);
      return;
    }

    btn.disabled = true;
    btn.textContent = 'Estimating...';
    result.style.display = 'none';

    try {
      const resp = await fetch(RPC, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          jsonrpc: '2.0',
          method: 'aztb_estimateGas',
          params: [{ from: from, data: bytecode, gas: '0x' + parseInt(gas).toString(16) }],
          id: 1
        })
      });
      const data = await resp.json();
      if (data.error) {
        showResult('Error: ' + (data.error.message || JSON.stringify(data.error)), false);
      } else {
        const estimated = typeof data.result === 'string' && data.result.startsWith('0x')
          ? parseInt(data.result, 16)
          : data.result;
        showResult('Estimated gas: ' + Number(estimated).toLocaleString(), true);
      }
    } catch (e) {
      showResult('Network error: ' + e.message, false);
    } finally {
      btn.disabled = false;
      btn.textContent = 'Estimate Gas';
    }
  });
})();
`}</script>
